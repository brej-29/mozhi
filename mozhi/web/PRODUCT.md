# Mozhi

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A Tamil, Malayalam and English voice assistant that checks before it acts. Visitors speak or type, inspect routing decisions, and receive useful sourced responses. Returning users keep preferences, reminders and notes.

## Capabilities and Constraints

Static HTML and vanilla JavaScript modules. Existing engine contracts, CSP, SEO, Evidence, language and respect controls remain. Model and voice availability must be stated honestly. Text responses remain accessible without speech. No new external assets or connections.

## Accessibility & Inclusion

AA contrast in both themes, visible keyboard focus, excellent 390px layout, reduced motion, and polite reply announcements. Tamil and Malayalam wording remains a draft.
